WERKERS WERKSTATT – SIMSON APP VERSION 3.8
===========================================

NEU IN 3.8
- Fahrzeug-Dashboard
- geschätzter Marktwert
- Kaufpreis + Reparaturen + weitere Kosten = Gesamtinvestition
- Differenz Marktwert zu Investition
- Restaurationsfortschritt
- offene Arbeiten
- nächster Service
- Dokumentstatus
- Fahrzeughistorie als Zeitstrahl
- Kauf, Reparaturen, Wartungen, Dokumente, Fotos, Service und Restauration
- Timeline-Filter nach Ereignistyp
- alle Funktionen aus 3.7 bleiben enthalten

MARKTWERT
Der Marktwert wird in dieser Version bewusst manuell gepflegt. So wird kein
scheinbar aktueller Marktpreis ohne belastbare Datenquelle behauptet.

START
START_WINDOWS.bat → http://localhost:8080

ANDROID / CAPACITOR
npm install
npx cap add android
npx cap sync android
npx cap open android
